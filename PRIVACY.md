# AST Lens Privacy Notice

Effective date: 2026-10-03

AST Lens analyzes Java and Kotlin source code locally inside IntelliJ IDEA.

## Data collection

AST Lens does not collect telemetry, analytics, diagnostics, personal data, usage data,
or identifiers.

## Source code and analysis data

AST Lens does not transmit source code, file contents, file paths, graph data, or analysis
results to the developer or to external services. Analysis results and the incremental cache
remain in the local IDE process.

AST Lens writes analysis data to disk only when the user explicitly starts an export to JSON,
Mermaid, or Graphviz and chooses a destination file.

## Network access and third parties

AST Lens does not require an account, an API key, or a network service, and it does not include
advertising or third-party tracking SDKs. IntelliJ IDEA and other installed plugins operate under
their own privacy terms independently of AST Lens.
